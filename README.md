# Kerala Wedding Invitation

A mobile-first static wedding invitation, ready for GitHub Pages.

## Personalize

Edit the `weddingConfig` object at the top of `js/script.js`. Update the bride's name, reception time, WhatsApp number, website URL, and exact Google Maps links there.

The invitation includes a lightweight, soothing instrumental generated with the browser's Web Audio API. It begins only after the visitor opens the invitation and can be paused or resumed with the music control. No external audio file is required.

For a correct WhatsApp link, use the full country-code number without `+`, spaces, or punctuation (for example, `919876543210`).

## Preview

Open `index.html` directly or serve this directory with any static web server. No build step is required.
